# A股宏观面分析框架：从宏观状态识别到可执行信号

**研究口径**：本轮纳入 153 篇/份资料，覆盖2025—2026年全球投行与资管年度/中期展望、中国卖方策略、BIS/IMF/央行与官方统计说明，以及宏观金融、资产定价、实时预测和状态识别领域的顶刊论文与工作论文。框架面向A股中短期择时、仓位管理和风格配置，不用于替代个股基本面与交易风控。

## 一、核心结论

宏观分析不能采用“经济好则股市涨、经济差则股市跌”的单线逻辑。股票价格同时反映未来现金流、折现率、风险溢价和已计入预期。可执行框架必须依次回答五个问题：

1. **经济处于什么状态，状态是在改善还是恶化。**
2. **政策反应函数是否改变，实际金融条件是否随之放松或收紧。**
3. **宏观变化是否进入企业收入、价格、利润率和盈利预测。**
4. **当前估值已计入多少改善或恶化。**
5. **资金流、市场宽度和相对强弱是否确认。**

截至2026年的有效迭代主要有七点：一是从GDP—通胀四象限升级为“增长—通胀—信用—金融条件—盈利—定价”多层状态；二是从政策利率转向广义金融条件；三是区分纯政策冲击与央行信息冲击；四是将数据实际值、趋势、预期差、修订和扩散度分开；五是采用实时数据、混频模型和数据发布日期管理；六是允许结构突变、状态转换和参数时变；七是用连续评分和模型组合替代单一指标、固定阈值和机械行业轮动。

## 二、八层宏观分析框架

### 第一层：全球增长与外部流动性

监测全球制造业新订单、美国ISM新订单—库存、全球贸易量、美元指数、美元融资压力、中美利差、人民币汇率、铜油比和全球半导体周期。该层不直接给出A股方向，而是刻画外需、汇率约束和全球风险偏好。

### 第二层：中国实际增长

以制造业PMI新订单、新订单—产成品库存、综合PMI、工业增加值环比动量、服务业生产、消费、制造业/基建/房地产投资和物流用电高频指标构建增长状态。GDP同比仅用于事后确认，不作为高频交易主指标。

### 第三层：价格与利润周期

核心指标包括核心CPI、PPI同比与环比扩散、GDP平减指数、PMI投入—产出价格差、工业品价格广度、工业企业利润和库存周期。重点不是“通胀高低”，而是名义增长、产业链利润分配和利润率方向。

### 第四层：信用周期

至少拆分三种信用脉冲：总社融脉冲、剔除政府债的私人部门信用脉冲、企业与居民分部门信用脉冲。政府债占比上升后，仅使用总社融会高估实体部门信用改善。M1—M2、贷款需求、票据利率、信用利差和金融条件指数用于判断信用从货币市场进入实体部门的程度。

### 第五层：货币与金融条件

核心不是“是否降息”，而是DR007相对政策利率、R007—DR007、同业存单利差、实际利率、期限利差、信用利差、汇率和股价共同形成的金融条件。降息若伴随股价下跌、信用利差走阔，可能主要传递了经济坏消息，而非形成有效宽松。

### 第六层：财政、地产与政策执行

财政分析应从预算赤字升级为广义财政脉冲，覆盖一般预算、政府性基金、专项债、政策性金融和财政存款变化。地产须同时观察销售、二手房价格扩散、开发资金来源、土地成交和居民中长期贷款。政策文本只能作为事件信号，必须由资金拨付、信贷、项目开工和市场支持工具余额确认。

### 第七层：盈利与估值

宏观变量进入股票定价的关键桥梁是盈利预测修正。重点监测未来12个月EPS上调扩散、单季盈利广度、利润率、ROE、行业收入与库存。估值使用前瞻盈利收益率、股权风险溢价和横截面估值扩散，不能只看指数静态PE。

### 第八层：市场确认

成交、两融、ETF和公募资金流、市场宽度、波动偏度、股债相对强弱用于确认。市场价格本身包含前瞻信息，宏观模型与市场趋势冲突时，不应机械逆势交易，而应记录“宏观—市场背离”并等待盈利或流动性确认。

## 三、统一的数据处理规则

每个指标至少保存五个维度：

- **水平**：相对长期均值或临界值的位置。
- **动量**：1个月、3个月或13周变化，优先使用季调环比和3M/3M折年率。
- **扩散度**：改善行业、地区、企业或品种的占比。
- **预期差**：实际值减调查预期，并按历史误差标准化。
- **修订**：首次公布值与后续修订值的差异。

统一标准化建议采用扩展窗口或10年滚动窗口z分数，截断至[-3,3]，避免极端值控制综合得分。存在明显结构变化的指标，应加入口径哑变量、分段标准化或重建可比历史序列。

## 四、评分体系

### 1. 单指标评分

建议初始公式：

`单指标分 = 35%×动量z + 25%×水平缺口z + 25%×预期差z + 15%×扩散度z`

没有预期值的指标，将预期差权重按比例分配给动量和扩散度。高频金融指标可提高动量权重；低频基本面指标可提高扩散度和修订权重。

### 2. 模块评分

模块内不宜简单平均，建议采用**方向调整后的加权中位数**或截尾均值，以降低单一异常指标影响。初始权重如下，后续只能通过滚动样本外检验调整：

| 模块 | 初始权重 |
|---|---:|
| 国内增长 | 15% |
| 价格与利润周期 | 10% |
| 信用与金融条件 | 18% |
| 货币与市场流动性 | 15% |
| 财政、地产与政策执行 | 12% |
| 全球增长与外部约束 | 10% |
| 盈利与估值 | 12% |
| 市场确认 | 8% |

### 3. 总分和信号

综合分建议缩放到[-2,2]：

- **≥0.75**：宏观与定价共振，允许提高权益仓位。
- **0.25—0.75**：偏多，但需控制追涨和拥挤。
- **-0.25—0.25**：中性，主要依赖个股与行业因素。
- **-0.75—-0.25**：偏防御，降低高波动和高杠杆暴露。
- **≤-0.75**：宏观、金融条件和市场确认共同恶化，优先控制回撤。

仓位信号至少满足“三项确认中的两项”：增长/信用拐点、金融条件改善、盈利预测上修。单独降息、单月社融超预期或单次PMI反弹均不构成完整信号。

## 五、宏观状态与A股风格映射

| 增长动量 | 通胀/名义增长 | 信用和流动性 | 主要含义 |
|---|---|---|---|
| 上升 | 温和上升 | 放松 | 最有利于宽基、顺周期和盈利修复 |
| 上升 | 快速上升 | 收紧 | 资源、金融和定价权较强行业占优；高估值久期资产承压 |
| 下降 | 下降 | 放松 | 先交易政策与估值，后等待信用、订单和盈利确认 |
| 下降 | 上升 | 收紧 | 滞胀型压力，降低高杠杆和高久期，重视防御与实物资产 |
| 低位企稳 | 低位 | 私人信用未改善 | 可能只有流动性行情，持续性取决于盈利修正 |
| 增长一般 | 名义增长改善 | 盈利广度上升 | 即使实际GDP不强，股票仍可能转向盈利驱动 |

行业映射只作为二级输出。商业周期行业轮动在不同样本中并不稳定，必须加入估值、盈利修正、政策暴露和市场拥挤。

## 六、不同时间尺度的使用

### 日度：风险与金融条件

更新DR007、R007—DR007、同业存单、国债曲线、信用利差、人民币、美元、商品、成交、两融、市场宽度和波动。日度层主要用于风险控制和入场时点，不用于重估中期宏观状态。

### 周度：高频需求和资金

更新地产成交、土地、物流、工业品价格与库存、ETF申赎、融资资金、财政与政府债发行。周度层用于确认月度宏观拐点。

### 月度：主模型

PMI、金融数据、价格、工业、消费、投资、利润、财政和外汇数据进入主评分。每次发布后保存“发布时点数据库”，禁止用后续修订值回填历史回测。

### 季度：盈利和结构校准

更新GDP、平减指数、企业盈利、ROE、现金流、银行家问卷、国际收支和货币政策报告。季度层用于调整模块权重和中期情景，不宜频繁改变短期仓位。

## 七、回测与有效性检验

1. 使用真实发布日期和首次公布值，处理混频与数据缺口。
2. 采用扩展窗口或滚动窗口训练，严禁全样本标准化。
3. 与历史均值、简单趋势、单一PMI、单一信用脉冲和股债60/40等基准比较。
4. 同时报告年化收益、波动、最大回撤、换手、胜率、盈亏比和交易成本后收益。
5. 分别检验2008年后、2015年股市异常波动、2020年疫情、2022年地产下行、2024年后政策框架变化等子样本。
6. 检验信号衰减期：1周、1月、3月、6月、12月。
7. 采用模型组合、贝叶斯收缩或加权中位数，避免从大量指标中选择“历史最优参数”。
8. 对结构突变设置报警：指标关系、权重或残差连续偏离历史分布时，暂停自动提高仓位。

## 八、最小可行版本

在数据和开发资源有限时，可先运行18项核心指标：

全球制造业新订单、DXY、USD/CNH；制造业PMI新订单、新订单—库存、工业增加值动量；PPI动量、投入—产出价格差；私人信用脉冲、企业中长期贷款、M1—M2、信用利差；DR007利差、同业存单利差；广义财政脉冲、地产销售；EPS上调扩散、市场宽度。

这18项已覆盖外部约束、增长、名义增长、信用、流动性、政策、盈利和市场确认。其余指标用于分解原因和提高稳健性，而不是简单增加模型复杂度。

2026-08-15 · 宏观/大宗商品研究、资产配置、交易与风险管理 · 全球原油及区域/品质价差

短期（0—3个月）：边际物理稀缺主导。 优先看商业库存可用度、近端月差、实货升贴水、炼厂利润、物流、有效闲置产能和真实供应中断；年度供需差只作约束。[O1][O2]

中期（3—18个月）：预期库存路径和生产者反应函数主导。 核心变量是OPEC+纪律与闲置产能、非OPEC增量、项目投产、资本开支及需求弹性。[A3][A14]

长期：只输出情景区间。 递减率、投资、成本、效率、电动化、航空/石化和政策路径共同决定均衡；IEA与OPEC长期需求分歧应转化为情景权重与敏感性。[O5][O7]

预测架构：结构识别 + 实时Nowcast + 分期限模型组合 + 尾部情景。 金融变量用于识别风险溢价、拥挤度和放大机制，须由库存、期限结构和实货验证。[A1][A7][O11]

3. 油价是库存约束下的跨期价格：供需平衡、便利收益和风险溢价共同作用

3.1 物量恒等式：供需差最终必须体现在库存或未观测差项

ΔIt = St − Dt

理论上供需差对应库存变化；实务中还存在在途、未报告库存和统计差。IEA保留“miscellaneous-to-balance”，且非OECD数据时效与完整性较弱，因此月度全球平衡表不应被强行闭合。[O1]

3.2 期限结构：当前库存稀缺会提高便利收益，使近端更强

Ft,T = St · exp[(rt + ut − yt)(T−t)]

r为融资成本，u为持有成本，y为便利收益。可用库存越低，便利收益通常越高、近端越强；远期升水扩大则提高储油激励。[O2]

约束：backwardation同时受现货稀缺、风险溢价、资金成本、季节性和合约技术影响，必须与库存、实货基差、炼厂利润和物流交叉验证。

3.3 建议构造“库存可用度”而非只看绝对库存

DaysSupplyt = CommercialStockst / ExpectedDailyDemandt:t+h
InventoryZt = (It − SeasonalMedianweek(t)) / SeasonalScaleweek(t)

库存至少同时保留绝对量、同比/季节分位、需求天数、可动用商业库存及地区/品种分布；单看绝对库存容易失真。[O1]

3.4 油价输出应被理解为状态依赖函数

Pt = f(PhysicalScarcityt, Et[Balance], Optionalityt, RiskPremiumt, FinancialConditionst, Quality/Locationt)

价格对同等供需冲击的反应取决于库存、闲置产能、物流和需求弹性；短期需求价格弹性本身也随时间变化。[A3]

4. 指标体系：短期优先物理市场，中期优先预期库存路径，金融变量最后确认

证据优先级：真实物理量 → 期限结构/实货 → 宏观与平衡表 → 金融与情绪。重大方向判断至少需要两个独立层级同向确认。

5. 多信号交叉验证：价格本身不是证据，价格与物理状态的一致性才是证据

高置信度物理收紧

价格↑ + backwardation加深 + 实货升贴水↑ + 商业库存季调后↓ + 裂解/炼量不弱。

现货与跨期同步确认；优先排查供给中断、需求超预期或补库。

事件风险溢价先行

价格↑ + 期权上行偏度↑，但实货基差/近月差变化有限、库存未下降。

风险溢价先行；若物理指标未跟进，溢价更易回吐。

需求/炼化走弱

价格↓ + 裂解↓ + 炼量↓ + 产品库存↑ + 宏观活动下行。

产品端先弱于原油端；可信度高于单看PMI或GDP。

库存信号冲突

库存↓，但月差不强、实货不强。

先查位置/品质、战略库存、在途、出口、检修和统计修订，排除不可用库存下降。

5.1 统一因子得分，但不让统计标准化掩盖经济含义

Scoreh,t = Σk wh,k,t · qk,t · signk · zk,t

z用滚动/扩展窗口稳健标准化（median/MAD并截尾）；q反映数据质量与时效；w由样本外表现决定，并按H0—H3分别估计。

输出：方向概率、价格区间、波动率、尾部风险、置信度及否证条件；不输出缺乏经济含义的伪精确综合分。

6. 模型体系应把“解释过去”和“预测未来”分开

6.1 结构识别层：回答“为什么涨/跌”

基准：月度Bayesian SVAR / sign-restricted SVAR，至少含全球产量、全球活动、实际油价和库存；按需加入月差、运费和预期变量。冲击分为供给、全球需求、油品特定/预防性需求。[A1][A2]

识别纪律：先验、符号限制和弹性范围必须做敏感性，并报告历史分解的不确定度。[A4]

6.2 实时Nowcast层：回答“本月/本季真实平衡可能在哪里”

用混频动态因子、MIDAS或Bayesian mixed-frequency VAR，将日/周/月数据映射到当月供给、需求和库存；每次更新记录预测修正来源。

6.3 价格预测层：回答“未来1—18个月价格分布如何”

首选分期限模型组合。 基准至少包括不变价/随机游走、期货曲线、库存/期限结构、VAR/BVAR、动态因子和正则化/树模型。实时组合在相关研究中可在最长18个月的多个期限上优于不变价基准。[A7]

序列定义风险：近期研究提醒，月均油价和月末油价的可预测性结论可能不同。所有模型必须固定目标序列定义；若目标用于交易，应优先匹配可交易结算价，而不是为提高统计显著性随意改用月均价。[A16]

6.4 状态转换层：允许弹性和反应函数变化

用TVP-BVAR、Markov-switching或rolling coefficients处理需求弹性、页岩供给弹性和OPEC+反应函数的时变性。

6.5 波动与尾部层：价格均值和风险分布分开建模

均值与尾部分开建模：短期用IV/skew、HAR/GARCH或分位数模型；地缘用事件树；长期用情景。输出P10/P50/P90等可验证分位数。

7. 地缘政治的研究单位应从“新闻条数”转为“净损失桶×持续时间×缓冲能力”

GPR衡量风险强度，不直接给出油价方向；冲突可同时影响供应、需求、航线、战略库存和OPEC+响应。[A11]

7.1 标准事件树

NetLosst = pt · [GrossAtRisk − Rerouting − SpareCapacityDeploy − StrategicRelease] − DemandDestruction
CumulativeLoss = Σt=1..T NetLosst · Δt

事件参数至少包括：发生概率、受影响桶、替代航线、保险/船舶约束、有效闲置产能、战略库存、需求破坏和持续时间；再按库存分位与期限结构定价。

步骤必须回答的问题建议证据
1. 物理暴露多少产量/出口真的依赖该设施、海峡、管道或制裁豁免？公司/政府产量、港口装船、船舶跟踪、管网能力
2. 替代能力能否绕行、换油种、改港口、动用库存？管线/港口余量、运距、品质匹配、商业库存
3. 生产者响应其他产油国能在几天/几周内增加多少可持续产量？有效闲置产能、历史增产速度、政策意愿
4. 需求破坏价格上升是否会反过来削弱交通、炼化和工业需求？裂解、销量、航班、工业活动、地区价格弹性
5. 市场确认物理市场是否真的在付更高的近端价格？实货升贴水、M1-M2、运费、库存、期权偏度

8. OPEC+研究重点是“反应函数”和“有效闲置产能”，而非新闻稿里的名义配额

8.1 自建有效闲置产能

ESCt = Σi NominalSparei,t × Availabilityi,t × QualityMatchi,t × Logisticsi,t × Willingnessi,t × RampSpeedi,t

ESC是工程指标。 它把名义闲置产能折算为目标期限内真正可替代的桶；闲置产能同时影响供给弹性和尾部风险。[A14]

8.2 估计OPEC+反应函数

ΔQOPEC+t+1 = f(PriceGap, InventoryGap, NonOPECGrowth, ESC, FiscalPressure, Cohesion, GeopoliticalConstraint)

用历史会议与实际产量估计有序选择、logit/probit或规则型贝叶斯模型，预测在不同价格、库存和非OPEC供给状态下的增产/减产概率。

9. 需求分析从“GDP×油耗弹性”下沉到产品、行业与地区

需求应下沉到产品、行业和地区。 原油需求先体现为炼厂投入，最终由汽油、柴油/航煤、石化原料等终端需求和炼厂利润决定。[O1]

需求层关键指标研究含义高频替代指标
交通—汽油道路里程、零售销量、车辆保有/效率、价格发达经济体季节性明显；长期受EV和效率压制移动/拥堵、汽油裂解、周度销量
货运/工业—柴油工业生产、制造PMI、卡车/货运、建筑对全球制造和贸易周期更敏感港口吞吐、运价、卡车里程
航空—航煤RPK/ASK、国际航班、票价、机队效率后疫情结构变化和航空效率需单独估计航班跟踪
石化—石脑油/LPG乙烯/芳烃利润、裂解装置开工、原料切换中长期增长的重要来源，但受产能过剩与原料替代影响naphtha cracks、PDH利润
发电/其他气油比、电力紧缺、气候、燃料替代在高气价、极端天气或地区电力短缺时阶段性放大天然气价格、用电负荷

中国需拆分进口、炼量、库存和产品出口。 进口增加可能来自消费、商业/战略补库或套利，不能直接等同需求增长；JODI等跨国数据必须保留时效与完整性标签。[O10]

10. 中长期价格由“递减率—投资—成本曲线—替代需求”共同约束，必须使用情景

10.1 供给侧：先算维持产量需要的投资，再算增量

新增产能先抵消自然递减，剩余部分才构成净增量；项目级供给分析应延伸到投产和爬坡。[O4]

NetSupplyGrowth = NewCapacity + Recovery − NaturalDecline − PlannedMaintenance − UnplannedOutage

资本开支拆分实际投资量与成本通胀；项目按FID、在建、试产、爬坡、平台期分层并估计延误概率。

10.2 需求侧：政策和技术采用路径差异足以改变长期均衡

长期需求分歧很大：IEA 2025 Current Policies Scenario到2050年约113 mb/d，OPEC WOO 2025接近123 mb/d。至少保留现行政策、加速转型、低转型/高需求、供给投资受限四类情景。[O5][O7]

10.3 长期价格不直接等于成本曲线

边际成本只提供中长期约束；风险资本、税费、融资/地缘溢价、OPEC+管理和需求弹性共同决定可持续价格带。

11. 数据工程：油价研究最容易被实时性、修订和口径差异污染

11.1 数据库必须支持vintage

PrimaryKey = (series_id, period, as_of, release_time, revision_id)

回测必须使用当时可见vintage；OECD月度数据会修订，非OECD数据还存在明显发布滞后。[O1]

11.2 推荐字段

字段含义治理要求
series_id唯一序列禁止用显示名称作为唯一键
period数据对应期周/月/季度规范化
release_time首次对市场可见时间精确到时区；防止日内前视
as_of数据库快照时间每次修订保留历史版本
unitb/d、kb/d、mb/d、mb、美元/桶等存原单位与标准单位
scopecrude、NGL、total liquids、product禁止跨口径直接相减
stock_typecommercial / strategic / primary / floating商业与战略库存分开
quality_flag官方/估算/缺失/修订/替代值进入模型权重 q
source原始来源记录链接、表名、发布时间

11.3 数据源优先级

数据优先级：A级官方/交易所/PRA；B级顶级期刊、央行与国际组织；C级一线投行；D级船舶、卫星、私营估算与媒体。A级定基准，D级提时效并以后续官方数据校验。

JODI的timeliness、completeness、comparability可直接映射为质量标签。[O9]

12. 回测：首先证明预测信息存在，再讨论交易收益

12.1 样本外设计

  1. 真实时间切分：rolling/expanding window；每一时点只允许使用当时已发布vintage。
  2. 基准：不变价/随机游走、期货曲线、简单季节模型。复杂模型不能只和较弱基准比较。
  3. 期限：1周、1月、3月、6月、12月、18月分别评估，不能把一个期限的胜率推广到所有期限。
  4. 指标：价格点预测用MAE/RMSE/MSPE；方向用hit ratio；概率/分布用Brier、CRPS或log score。
  5. 统计检验：非嵌套模型可用Diebold-Mariano类比较；嵌套模型使用适当修正。报告经济显著性和置信区间。
  6. 状态鲁棒性：按库存高/低、backwardation/contango、OPEC spare高/低、衰退/扩张、地缘事件分层。

12.2 交易回测放在第二层

预测稳定后再映射交易；回测计入滚动、bid-ask、冲击成本、融资/保证金、限仓和跳空。期货收益含roll yield，spot预测准确率不等于策略收益。

12.3 监控模型衰减

每个因子监控rolling IC、方向胜率、参数漂移、缺失率和revision surprise；失效时自动降权并记录制度变化。

13. 日/周/月研究流程：固定问题、固定证据顺序、固定否证条件

频率先看什么再看什么最终更新
日内/每日Brent/WTI/Dubai/SC；M1-M2；实货基差；裂解；运费；期权停产/制裁/港口/海峡事件；美元和利率H0事件树、物理收紧/放松判断、价格已计入程度
每周EIA库存与炼厂开工；CFTC；钻机/完井；船期与浮仓库存季节偏离、产品端、地区套利H1库存路径、因子分数、情景概率
每月IEA OMR、OPEC MOMR、EIA STEO、JODI全球平衡表修订、OPEC+实际产量、需求地区/产品分解H1/H2季度供需与均价区间；结构冲击分解
每季/半年公司capex、项目/FID、成本、政策、IEA Oil/WEO、OPEC WOO、World Bank页岩/深水/油砂投资弹性、EV/效率、炼能结构H2/H3情景和长期价格带

13.1 标准周报/日报模板

首段只写结论：物理状态 → 1—3个月库存方向 → 定价充分度 → 最大上/下行风险。证据顺序固定为：价格/曲线、库存/炼化、供给、需求、金融/持仓、事件树、模型区间、否证条件。

13.2 研究结论必须带否证条件

否证条件必须可观测，如M1-M2回归中性、商业库存连续季调累积、实货升贴水/裂解转弱、OPEC+实际增产超预期；阈值由历史回测确定。

14. 常见误判：多数来自把代理变量当成目标变量

误判为什么错修正
只看年度“供需缺口”忽略库存起点、在途、地区/品质错配和数据修订转成预期库存路径 + 月差 + 实货验证
把OPEC+配额当产量基准、豁免、执行率、补偿减产不同用二手来源实际产量和出口交叉验证
把名义闲置产能全部当可用质量、物流、爬坡速度、政治意愿会折损使用ESC有效闲置产能
看到GPR上升就做多油地缘风险也可能打击需求或没有实际桶损失估计barrels-at-risk、持续时间、替代与库存
看到CFTC净多增加就判基本面强持仓分类是交易者类别，存在趋势跟随和套保持仓只做拥挤度/放大器，先看物理层
美元走强就机械看空油油价、美元、利率可能被共同宏观冲击驱动SVAR/局部投影识别共同冲击，控制风险状态
只看原油库存炼厂可能把原油库存转成产品库存，终端需求并未变强原油+产品库存+裂解+炼量联读
用今天修订数据回测过去严重前视偏差保留vintage与发布时间
长期用单点油需预测政策/技术路径分歧巨大用IEA/OPEC等多情景并给权重/敏感性
复杂ML模型胜过弱基准即上线可能只是过拟合或未计成本与no-change、futures、简单组合严格样本外比较

15. 最小可行实现：先把物理层和实时回测做对，再增加模型复杂度

15.1 Phase 1：研究底座

  • 统一Brent/WTI/Dubai/SC价格、月差、主要裂解和实货基差。
  • 接入EIA周度库存、IEA/OPEC/JODI月度数据，建立商业/战略库存分层。
  • 计算季节库存分位、days of forward demand、M1-M2/M1-M6、Brent-WTI/Brent-Dubai。
  • 建立OPEC+配额—实际—执行率—有效闲置产能表。
  • 上线四期限的方向/区间输出，并以no-change与futures为基准。

15.2 Phase 2：提高解释和实时性

  • 混频Nowcast：工业活动、船运、航班、炼化、期权、CFTC、钻机。
  • Bayesian SVAR历史分解；TVP/状态切换处理弹性变化。
  • 地缘事件数据库：事件、实际损失桶、持续时间、替代能力、价格/曲线响应。
  • 投行/机构预测统一存成“当时预测vintage”，比较误差而不是只看最新观点。

15.3 Phase 3：模型组合和研究自动化

  • 按期限动态组合模型；权重来自滚动样本外表现。
  • 建立因子衰减监控、数据质量告警、修订冲击监控。
  • 输出概率分布、情景树和否证条件；再映射到期货/期权策略。
建议的最终研究产品只有五个核心字段：①物理状态；②未来库存方向；③价格区间/概率；④上/下行尾部情景；⑤判断置信度及否证条件。其他数据都服务于这五个字段。

16.4 文献使用原则

文献分工：顶级论文用于结构识别和预测方法；官方/国际组织用于口径、实时数据和情景；PRA/交易所用于价格发现；投行研究用于市场实践校验。机构目标价不作为模型真值。

适用边界：研究与模型设计框架，不构成投资建议；阈值、权重、弹性和仓位映射均须基于真实时间数据单独回测。

说明：ESC与综合因子得分为工程化构造，须用历史数据校准，不属于官方统计。

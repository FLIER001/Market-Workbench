# 国内增长与景气评分模块（V1.1）

## 1. 总体结构

```text
DomesticGrowthClimate =
国内官方景气 45%
+ 国内市场化景气 20%
+ 国内实际活动 15%
+ 增长结果确认 20%
```

| 模块      |  权重 |
| ------- | --: |
| 国内官方景气  | 45% |
| 国内市场化景气 | 20% |
| 国内实际活动  | 15% |
| 增长结果确认 | 20% |

原则：领先指标优先；原始指标与其线性派生指标不得同时计权。全球指标统一归入“全球外部”模块，本模块只处理国内增长。

## 3. 财新PMI处理

2025年7月后，“财新中国PMI”更名为 **RatingDog中国PMI**，底层仍为S&P Global PMI体系。

数据库直接连续拼接：

```text
Caixin Manufacturing PMI
→ RatingDog China Manufacturing PMI

Caixin Services PMI
→ RatingDog China Services PMI
```

不要建立两条历史序列。

现有数据停留在2025-08，优先检查抓取关键词/接口是否仍限定“财新/Caixin”。

## 4. PMI评分

禁止仅按50荣枯线评分。

推荐：

```text
PMI_Score =
0.5 × Level
+ 0.3 × Momentum
+ 0.2 × Surprise
```

无一致预期：

```text
PMI_Score =
0.6 × Level
+ 0.4 × Momentum
```

### Level

优先采用历史Z-score或历史分位数，不直接使用 `PMI-50`。

```text
Z = (Current - HistoricalMean) / HistoricalStd
```

### Momentum

```text
Momentum =
0.6 × (X_t - X_t-1)
+ 0.4 × (MA3_t - MA3_t-1)
```

### Surprise

```text
Surprise = Actual - Consensus
```

## 5. 订单库存差

```text
OrderInventorySpread =
PMI新订单 - PMI产成品库存
```

解释：

| 状态       | 周期含义     |
| -------- | -------- |
| 新订单↑、库存↓ | 最强，补库存预期 |
| 新订单↑、库存↑ | 需求改善     |
| 新订单↓、库存↓ | 去库存      |
| 新订单↓、库存↑ | 最弱，被动累库  |

用于领先判断制造业库存周期，权重4%。

## 6. 实际活动指标

不直接按同比绝对增速评分，使用景气动量：

```text
IndustrialMomentum =
工业增加值同比 - 过去12个月均值
```

或：

```text
IndustrialMomentum = MA3 - MA12
```

服务业生产指数同理。

---

## 7. 增长结果确认

结果确认子模块占总分 **20%**：

```text
GrowthConfirmation =
0.35 × GDP同比
+ 0.35 × 工业企业营收同比
+ 0.30 × 设备工器具投资同比
```

GDP仅作结果确认，不作为高频领先指标；工业营收和设备投资用于确认订单与生产是否进入收入和资本开支。

CPB世界贸易量、全球制造业PMI和OECD CLI统一归入“全球外部”模块。需要在本模块展示时只做引用，不再次计分。

国内增长链条：

```text
订单与预期 → 工业/服务业动量 → 营收与设备投资 → GDP确认
```

## 8. 特殊指标

### PMI生产经营预期

长期中枢明显高于50，必须按自身历史分布评分：

```text
Score = HistoricalPercentile
```

不能使用：

```text
>50 = 扩张
```

### OECD CLI

重点看方向：

```text
CLI_Score =
0.3 × Level
+ 0.5 × Momentum
+ 0.2 × Acceleration
```

其中：

```text
Momentum = CLI_t - CLI_t-1
Acceleration = Momentum_t - Momentum_t-1
```

### CPB世界贸易

采用平滑数据：

```text
3MMA同比
+
3MMA环比年化
```

不使用单月环比直接评分。

## 9. 景气状态

总分标准化至0—100：

|    得分 | 状态   |
| ----: | ---- |
|   ≥70 | 强扩张  |
| 60—70 | 扩张   |
| 50—60 | 弱扩张  |
| 40—50 | 弱收缩  |
| 30—40 | 收缩   |
|   <30 | 深度收缩 |

同时必须输出动量：

```text
Score = 39.7
MoM = -5.8
State = 收缩
Direction = 恶化
```

---

## 10. 四象限

使用：

```text
横轴 = 景气水平
纵轴 = 景气动量
```

| 水平 | 动量 | 状态 |
| -- | -- | -- |
| 低  | 上升 | 复苏 |
| 高  | 上升 | 扩张 |
| 高  | 下降 | 放缓 |
| 低  | 下降 | 衰退 |

四象限用于资产/行业配置；0—100分用于横向比较。

---

## 11. 缺失与滞后数据

禁止缺失值直接计0分。

```text
EffectiveWeight =
BaseWeight × FreshnessFactor
```

建议：

| 滞后   | FreshnessFactor |
| ---- | --------------: |
| 当月   |            1.00 |
| 1个月  |            0.90 |
| 2个月  |            0.75 |
| ≥3个月 |            0.50 |

计算时重新归一化有效权重。

# A股板块评分系统技术方案（防追涨优化版）

> 文档版本：V1.1  
> 适用范围：A股板块轮动、行业与主题共振、个股环境评分、中短期择时  
> 核心修订：由单一趋势总分改为“板块强度分 + 板块机会分”双评分体系  
> 更新频率：日频  
> 建议回测区间：2019年至今，实际使用时以数据完整性为准  

---

## 1. 项目背景

现有行业评分能够识别传统行业层面的趋势、景气和估值状态，但A股市场中的大量投资主线具有明显的跨行业特征。

例如：

- AI算力涉及电子、通信、计算机和电力设备；
- 机器人涉及机械设备、电子、汽车零部件和计算机；
- 低空经济涉及国防军工、机械设备、通信、计算机和交通运输；
- 消费出海涉及家电、轻工制造、纺织服饰、汽车零部件和跨境电商。

因此，需要在行业评分之外建立独立的板块评分系统，用于识别跨行业产业链、技术路线和长期投资主题。

但板块评分不能简单堆叠趋势、涨幅、均线、扩散和成交等量价指标。若多个高度相关的趋势指标重复计分，模型容易形成以下偏差：

```text
板块上涨
→ 收益率上升
→ 相对收益上升
→ 站上均线比例提高
→ 创新高股票增加
→ 成交额占比提高
→ 融资资金流入
→ 多个维度同时获得高分
```

这种模型实际上是在描述“当前最强板块”，不一定能够识别“未来收益风险比最优的板块”，并可能产生明显的追涨杀跌倾向。

因此，本方案将板块评分拆分为两个独立模块：

1. **板块强度分**：判断当前是否已经形成趋势和市场共识；
2. **板块机会分**：判断当前价格位置下是否仍具有合理的未来收益风险比。

---

## 2. 系统目标

板块评分系统主要回答以下问题：

1. 当前市场最强的产业主线是什么；
2. 哪些板块正在从低位进入启动阶段；
3. 哪些板块已经形成趋势，但价格和交易过度拥挤；
4. 哪些板块基本面改善，但市场尚未充分确认；
5. 哪些板块出现扩散转弱、龙头独涨或趋势退潮信号；
6. 个股是否同时得到行业和板块环境支持；
7. 板块评分相对于行业评分是否能够提供额外预测信息。

---

## 3. 系统总体架构

建议将A股中观评分体系分为三层：

```text
中观市场环境评分
├── 行业评分
├── 板块评分
│   ├── 板块强度分
│   └── 板块机会分
└── 风格评分
```

### 3.1 行业评分

行业评分基于申万一级行业等稳定分类，用于回答：

> 哪个行业的整体盈利、估值、趋势和资金状态更优？

特点：

- 分类互斥性较强；
- 覆盖全部A股；
- 更适合中观行业景气分析；
- 更适合分析行业利润、估值和机构配置。

### 3.2 板块评分

板块评分基于产业链、技术路线和长期投资主题，用于回答：

> 当前资金正在交易哪条产业主线，该主线是否仍具有参与价值？

特点：

- 一只股票可以属于多个板块；
- 板块可以跨越多个行业；
- 更贴近A股实际交易逻辑；
- 对主线识别、启动和退潮更敏感；
- 需要自主维护成分股和业务相关度。

### 3.3 风格评分

大盘、小盘、成长、价值、红利、低波和质量属于风格因子，不纳入本板块评分系统，后续单独建设。

## 4. 设计原则

### 4.1 避免趋势重复计分

以下指标高度相关，不应在多个维度重复大权重计分：

- 20日、60日、120日收益；
- 多套均线排列；
- 趋势斜率；
- 距阶段高点；
- 相对多个市场基准的超额收益；
- 站上均线比例；
- 创新高比例；
- 成交额和换手率。

每类信息只保留少量代表性指标。

### 4.2 强度不等于机会

强势板块可能已经处于高位拥挤阶段，弱势板块也可能处于基本面改善但市场尚未确认的早期阶段。

因此：

```text
强度分用于确认趋势；
机会分用于判断是否值得参与。
```

### 4.3 边际变化优于绝对水平

相比“当前有多少股票站上MA20”，更应关注“站上MA20的股票比例是否正在改善”。

相比“成交额占比是否高”，更应关注“成交额占比是否从低位持续回升，以及是否已经过热”。

### 4.4 明确高位和拥挤惩罚

趋势指标只能确认市场共识，不能自动转化为买入信号。必须增加：

- 累计涨幅惩罚；
- 距均线偏离惩罚；
- 成交拥挤惩罚；
- 龙头集中度惩罚；
- 扩散背离惩罚。

### 4.5 基本面和盈利预期优先

板块机会分应以以下信息为核心：

- 基本面景气；
- 盈利预测变化；
- 产业高频数据；
- 估值匹配；
- 价格位置；
- 拥挤程度。

### 4.6 稳定、可解释、可回测

板块定义、成分股、业务相关度和权重必须保存历史版本，避免使用当前成分股回溯历史。

## 6. 成分股体系

### 6.1 成分股分层

每个板块设置三级成员类型。

| 类型 | 权重 | 定义 |
|---|---:|---|
| 核心成分股 | 1.00 | 主营业务直接属于板块，收入、利润或估值高度相关 |
| 产业链受益股 | 0.50 | 提供材料、设备、零部件或配套服务 |
| 观察股 | 0.25 | 业务处于早期验证阶段，暂不进入正式板块指数 |

### 6.2 纳入标准

股票至少满足以下条件之一：

1. 相关业务收入占比达到20%；
2. 相关业务利润占比达到20%；
3. 公司为该产业链关键环节龙头；
4. 新业务尚未形成较高收入，但已有明确订单、产能或量产进度；
5. 市场对公司的主要估值逻辑来自该板块。

### 6.3 排除标准

以下股票不纳入正式成分股：

- 仅表示“关注”或“研究”相关业务；
- 仅持有少量相关公司股权；
- 相关业务对收入和利润影响极低；
- 概念主要来自媒体推测；
- 近60日日均成交额位于全市场后10%；
- 长期停牌；
- ST或存在重大退市风险；
- 上市不足60个交易日。

### 6.4 多板块归属

一只股票原则上最多进入3个正式板块。

记录字段：

```text
stock_code
board_code
membership_type
business_relevance
effective_date
expire_date
evidence_source
version
```

### 6.5 调整频率

- 正式成分股调整：每季度一次；
- 板块定义评估：每半年一次；
- 临时调整：主营业务重大变化、重组、退市或长期停牌；
- 历史版本：永久保留。

## 7. 板块指数构建

### 7.1 初始权重

```math
raw\_weight_i
=
relevance_i
\times
\sqrt{float\_market\_cap_i}
```

其中：

- `relevance_i`：业务相关度；
- `float_market_cap_i`：自由流通市值。

### 7.2 权重约束

- 单只股票权重上限：8%；
- 前五大股票权重合计上限：35%；
- 单一申万一级行业权重上限：50%；
- 核心成分股合计权重不低于70%。

### 7.3 双指数体系

限权市值指数：

```math
R_{cap,t}
=
\sum_{i=1}^{N} w_{i,t-1}r_{i,t}
```

等权指数：

```math
R_{equal,t}
=
\frac{1}{N}\sum_{i=1}^{N}r_{i,t}
```

综合板块指数：

```math
R_{board,t}
=
0.6R_{cap,t}
+
0.4R_{equal,t}
```

综合指数用于趋势和收益计算；等权指数相对限权市值指数的变化用于判断板块内部扩散。

## 8. 双评分体系

板块评分由两个独立分数组成：

```text
板块强度分：Strength Score
板块机会分：Opportunity Score
```

不建议仅使用一个总分直接决定买卖。

# 第一部分：板块强度分

## 9. 板块强度分定义

板块强度分用于回答：

> 当前板块是否已经形成趋势、扩散和资金共识？

强度分不直接表示买入价值。

评分结构：

| 维度 | 权重 |
|---|---:|
| 相对趋势 | 25 |
| 扩散改善 | 30 |
| 资金确认 | 20 |
| 趋势稳定性 | 15 |
| 龙头集中度 | 10 |
| 合计 | 100 |

---

## 10. 相对趋势评分

### 10.1 指标精简原则

不再同时使用：

- 20日、60日、120日绝对收益；
- 多套均线排列；
- 趋势斜率；
- 距阶段高点；
- 相对多个基准的超额收益。

仅保留两个核心指标：

- 20日相对全A超额收益；
- 60日相对全A超额收益。

### 10.2 计算公式

```math
ER_{20}
=
R_{board,20}
-
R_{market,20}
```

```math
ER_{60}
=
R_{board,60}
-
R_{market,60}
```

相对趋势：

```math
RelativeTrend
=
0.6 \times Score(ER_{20})
+
0.4 \times Score(ER_{60})
```

### 10.3 设计理由

- 20日指标反映短期板块轮动；
- 60日指标反映趋势持续性；
- 不使用120日收益，避免长期强势板块持续占据高分；
- 不重复使用MA20、MA60和趋势斜率。

---

## 11. 扩散改善评分

扩散改善是强度分中的核心指标，但不使用单纯绝对水平，而强调边际变化。

### 11.1 核心指标

| 指标 | 权重 |
|---|---:|
| MA20覆盖率5日变化 | 10 |
| 成分股20日收益中位数 | 8 |
| 等权指数相对限权指数变化 | 7 |
| 新高新低改善 | 5 |

### 11.2 MA20覆盖率

```math
Breadth_{MA20,t}
=
\frac{\#(P_{i,t}>MA20_{i,t})}{N_t}
```

扩散脉冲：

```math
BreadthImpulse_t
=
0.6(B_t-B_{t-5})
+
0.4(B_t-B_{t-20})
```

### 11.3 等权相对强弱

```math
EqualCapSpread_t
=
R_{equal,20}
-
R_{cap,20}
```

若等权指数开始跑赢限权市值指数，说明上涨从龙头向更多成分股扩散。

### 11.4 评分逻辑

| 当前MA20覆盖率 | 5日变化 | 判断 |
|---:|---:|---|
| 90% | -5个百分点 | 高位扩散转弱 |
| 65% | +20个百分点 | 扩散快速改善 |
| 40% | +2个百分点 | 弱势且改善有限 |

模型优先识别第二种状态，而不是机械地给第一种状态最高分。

---

## 12. 资金确认评分

### 12.1 核心指标

| 指标 | 权重 |
|---|---:|
| 成交额占比变化 | 8 |
| ETF份额变化 | 5 |
| 融资余额变化 | 4 |
| 机构或大单资金变化 | 3 |

### 12.2 成交额占比

```math
TurnoverShare_t
=
\frac{Turnover_{board,t}}
{Turnover_{market,t}}
```

成交额占比脉冲：

```math
FlowImpulse_t
=
MA_5(TurnoverShare_t)
-
MA_{20}(TurnoverShare_t)
```

### 12.3 非线性处理

成交活跃度不采用线性加分。

```text
历史分位 0%—30%：关注度不足，低分
历史分位 30%—80%：资金逐步确认，加分
历史分位 80%—95%：高活跃，得分趋于平缓
历史分位 95%—100%：进入拥挤区，不再加分
```

资金确认只表示趋势获得资金支持，不表示当前价格仍有吸引力。

---

## 13. 趋势稳定性评分

趋势稳定性用于区分稳定上行和剧烈波动反弹。

核心指标：

| 指标 | 权重 |
|---|---:|
| 20日最大回撤 | 6 |
| 收益波动率 | 4 |
| 上涨日占比 | 3 |
| 收益路径平滑度 | 2 |

建议使用收益风险比：

```math
TrendQuality
=
\frac{R_{20}}
{Volatility_{20}+\epsilon}
```

高收益但波动和回撤过大的板块，不应获得过高的稳定性得分。

---

## 14. 龙头集中度评分

龙头集中度采用反向评分。

### 14.1 收益贡献集中度

```math
Top3Contribution_t
=
\frac{\sum_{i \in Top3} w_i r_i}
{\sum_{i=1}^{N}w_i r_i}
```

### 14.2 评分规则

| 前3只股票收益贡献率 | 评分判断 |
|---:|---|
| 低于35% | 扩散充分，高分 |
| 35%—50% | 正常 |
| 50%—65% | 集中度偏高 |
| 高于65% | 龙头独涨，显著扣分 |

当板块指数上涨但上涨主要来自少数龙头时，强度质量较低。

---

## 15. 板块强度分公式

```math
StrengthScore
=
0.25RT
+
0.30BI
+
0.20FC
+
0.15TQ
+
0.10LC
```

其中：

- `RT`：相对趋势；
- `BI`：扩散改善；
- `FC`：资金确认；
- `TQ`：趋势稳定性；
- `LC`：龙头集中度反向评分。

# 第二部分：板块机会分

## 16. 板块机会分定义

板块机会分用于回答：

> 在当前价格和交易状态下，未来收益风险比是否仍具有吸引力？

评分结构：

| 维度 | 权重 |
|---|---:|
| 基本面景气 | 30 |
| 盈利预期变化 | 20 |
| 估值匹配度 | 15 |
| 价格位置 | 15 |
| 拥挤程度 | 15 |
| 催化持续性 | 5 |
| 合计 | 100 |

---

## 17. 基本面景气评分

### 17.1 核心指标

| 指标 | 权重 |
|---|---:|
| 营业收入增速及变化 | 5 |
| 扣非利润增速及变化 | 7 |

| ROE变化 | 3 |
| 产业高频景气 | 7 |
| 订单或资本开支变化 | 3 |

### 17.2 聚合方法

每个指标同时计算：

- 限权市值加权平均值；
- 成分股中位数；
- 正增长公司比例。

最终建议：

```math
FundamentalValue
=
0.4 \times WeightedMean
+
0.4 \times Median
+
0.2 \times PositiveRatio
```

避免少数龙头掩盖板块内部多数公司的真实经营状况。

## 19. 估值匹配度评分

估值不能简单理解为越低越好。

### 19.1 板块适配指标

| 板块类型 | 主要估值指标 |
|---|---|
| 成熟盈利板块 | PE、PB、股息率、自由现金流收益率 |
| 高成长科技 | PE、PEG、PS |
| 周期资源 | PB、EV/EBITDA、商品价格位置 |
| 未盈利创新药 | PS、现金覆盖期、管线价值 |
| 高股息板块 | 股息率、自由现金流收益率 |

### 19.2 估值匹配逻辑

```text
低估值 + 基本面改善：高分
低估值 + 基本面恶化：不加分
高估值 + 盈利持续上修：中性或轻度扣分
高估值 + 盈利下修：明显扣分
```

可以构建PEG类指标：

```math
ValuationMatch
=
\frac{ExpectedGrowthPercentile}
{ValuationPercentile+\epsilon}
```

## 20. 价格位置评分

价格位置用于防止模型在短期高位继续加分。

### 20.1 核心指标

| 指标 | 权重 |
|---|---:|
| 20日累计涨幅分位 | 5 |
| 60日累计涨幅分位 | 4 |
| 距MA60偏离度 | 3 |
| 距120日高点距离 | 3 |

### 20.2 位置风险

```math
PositionRisk
=
0.35P(R_{20})
+
0.25P(R_{60})
+
0.20P(DistanceToMA60)
+
0.20P(DistanceToHigh)
```

其中`P`表示时间序列历史分位。

位置得分：

```math
PositionScore
=
100
-
PositionRisk
```

### 20.3 非线性处理

- 处于极低位置但趋势持续恶化：不得自动获得高分；
- 从低位企稳、基本面改善且扩散增强：高分；
- 短期快速上涨并明显偏离MA60：显著扣分；
- 高位横盘但盈利持续上修：适度保留分数。

## 21. 拥挤程度评分

拥挤程度采用风险反向评分。

### 21.1 核心指标

| 指标 | 权重 |
|---|---:|
| 换手率历史分位 | 4 |
| 成交额占比历史分位 | 4 |
| 融资余额增速分位 | 3 |
| 涨停集中度 | 2 |
| 龙头估值溢价 | 2 |

### 21.2 拥挤惩罚

```math
CrowdingPenalty
=
Penalty(Turnover)
+
Penalty(TurnoverShare)
+
Penalty(Margin)
+
Penalty(LimitUp)
+
Penalty(LeaderPremium)
```

惩罚上限建议设为20分。

### 21.3 典型高风险状态

- 换手率处于历史95%分位以上；
- 成交额占比处于历史95%分位以上；
- 融资余额短期增速处于历史95%分位以上；
- 板块连续出现大量涨停；
- 龙头股估值溢价显著扩大；
- 板块指数创新高，但扩散率下降。

## 22. 催化持续性评分

催化持续性只占5分，避免主观事件信息主导模型。

评估内容：

- 政策是否具有持续执行周期；
- 行业订单是否可验证；
- 产品周期是否处于早中期；
- 资本开支是否具有连续性；
- 催化是否已经被价格充分反映。

催化信息应采用结构化标签，而非直接使用新闻情绪。

## 25. 综合优先级评分

如业务系统必须输出单一排序，可计算：

```math
BoardPriority
=
0.55 \times OpportunityScore
+
0.45 \times StrengthScore
```

但设置以下硬约束：

```text
机会分低于40分：
不得进入“建议参与”名单。

强度分低于40分：
只能进入“左侧观察”名单，不进入趋势交易名单。

拥挤惩罚达到15分以上：
无论综合得分多高，标记为“强势但不追”。
```

## 26. 板块阶段信号

### 26.1 低位观察

条件：

- 机会分不低于65；
- 强度分低于50；
- 基本面或盈利预期正在改善；
- 价格位置低于历史50%分位；
- 拥挤程度低。

输出：

```text
LEFT_SIDE_WATCH
```

### 26.2 轮动启动

条件：

- 强度分由50以下升至60以上；
- 机会分不低于60；
- 10日排名提升至少8位；
- MA20覆盖率5日明显改善；
- 成交额占比上升但未进入95%分位。

输出：

```text
ROTATION_START
```

### 26.3 主线确认

条件：

- 强度分不低于70；
- 机会分不低于60；
- 板块排名进入前20%；
- 扩散改善和资金确认均为正。

输出：

```text
MAIN_TREND_CONFIRMED
```

### 26.4 强势但不追

条件：

- 强度分不低于75；
- 机会分低于45；
- 或拥挤惩罚达到15分以上；
- 或价格位置处于历史90%分位以上。

输出：

```text
STRONG_BUT_OVERHEATED
```

### 26.5 扩散背离

条件：

- 板块指数创新高或保持高位；
- MA20覆盖率连续3日下降；
- 等权指数开始跑输限权指数；
- 龙头贡献集中度持续上升。

输出：

```text
BREADTH_DIVERGENCE
```

### 26.6 趋势退潮

条件：

- 强度分跌破50；
- 5日排名下降超过8位；
- 板块指数跌破MA20；
- MA20覆盖率低于40%；
- 资金确认转负。

输出：

```text
TREND_EXIT
```

## 30. 每日计算流程

```text
1. 更新个股行情、复权因子和自由流通市值
2. 读取当日有效板块成分股版本
3. 计算限权市值指数、等权指数和综合板块指数
4. 计算20日和60日相对市场超额收益
5. 计算MA20覆盖率及其5日、20日变化
6. 计算等权指数相对限权指数表现
7. 计算成交额占比、ETF份额和融资变化
8. 计算趋势稳定性和龙头贡献集中度
9. 读取最新财务、盈利预测和产业高频数据
10. 计算估值匹配、价格位置和拥挤程度
11. 对各指标执行横截面和时间序列标准化
12. 计算板块强度分
13. 计算板块机会分
14. 计算综合优先级，但执行机会分和拥挤度硬约束
15. 识别左侧观察、轮动启动、主线确认、强势过热和退潮信号
16. 将板块得分映射至个股
17. 与行业评分合成个股市场环境分
18. 输出板块二维矩阵和监测榜单
```

## 31. 伪代码

```python
for trade_date in trading_calendar:

    constituents = load_effective_constituents(trade_date)

    for board in board_pool:

        stocks = constituents[board]

        cap_index = calc_capped_cap_index(stocks, trade_date)
        equal_index = calc_equal_weight_index(stocks, trade_date)
        board_index = 0.6 * cap_index + 0.4 * equal_index

        # 强度分
        relative_trend = calc_relative_trend(
            board=board,
            windows=[20, 60],
            benchmark="all_a"
        )

        breadth_impulse = calc_breadth_impulse(
            board=board,
            ma_window=20,
            change_windows=[5, 20]
        )

        flow_confirmation = calc_flow_confirmation(
            board=board,
            turnover_share=True,
            etf_share=True,
            margin_balance=True
        )

        trend_quality = calc_trend_quality(
            board=board,
            volatility_window=20,
            drawdown_window=20
        )

        leader_concentration = calc_leader_concentration(
            board=board,
            top_n=3
        )

        strength_score = (
            0.25 * relative_trend
            + 0.30 * breadth_impulse
            + 0.20 * flow_confirmation
            + 0.15 * trend_quality
            + 0.10 * leader_concentration
        )

        # 机会分
        fundamental = load_fundamental_score(board, trade_date)
        earnings_revision = load_earnings_revision_score(board, trade_date)
        valuation_match = calc_valuation_match(board, trade_date)
        position_score = calc_position_score(board, trade_date)
        crowding_score = calc_crowding_score(board, trade_date)
        catalyst_score = load_catalyst_score(board, trade_date)

        opportunity_score = (
            0.30 * fundamental
            + 0.20 * earnings_revision
            + 0.15 * valuation_match
            + 0.15 * position_score
            + 0.15 * crowding_score
            + 0.05 * catalyst_score
        )

        priority_score = (
            0.55 * opportunity_score
            + 0.45 * strength_score
        )

        state = classify_strength_opportunity(
            strength_score=strength_score,
            opportunity_score=opportunity_score
        )

        if opportunity_score < 40:
            state = "STRONG_BUT_OVERHEATED" if strength_score >= 70 else "AVOID"

        save_board_score(
            board=board,
            trade_date=trade_date,
            strength_score=strength_score,
            opportunity_score=opportunity_score,
            priority_score=priority_score,
            state=state
        )
```

## 33. 回测验证方案

### 33.1 核心检验问题

1. 强度分是否能够识别趋势延续；
2. 机会分是否能够提高未来收益风险比；
3. 强度高、机会低的板块是否更容易出现回撤；
4. 强度中等、机会高的板块是否更容易形成后续启动；
5. 双评分是否优于单一趋势评分；
6. 板块评分是否对行业评分提供增量信息。

### 33.2 分组回测

分别按照：

- 强度分五分组；
- 机会分五分组；
- 综合优先级五分组；
- 强度—机会二维组合分组。

观察未来：

- 5日收益；
- 10日收益；
- 20日收益；
- 相对全A超额收益；
- 胜率；
- 最大回撤；
- 收益回撤比；
- 换手成本后收益。

### 33.3 二维回测

重点比较：

| 组合 | 预期 |
|---|---|
| 高强度 + 高机会 | 未来收益较高，回撤可控 |
| 高强度 + 低机会 | 短期可能继续强，但后续回撤较大 |
| 低强度 + 高机会 | 中期启动概率较高，但需要等待趋势确认 |
| 低强度 + 低机会 | 收益较弱 |

### 33.4 消融实验

比较以下模型：

```text
模型A：单一趋势评分
模型B：板块强度分
模型C：板块机会分
模型D：强度分 + 机会分
模型E：行业评分 + 双板块评分
```

验证双评分体系是否真正降低追涨杀跌。

### 33.5 关键评价指标

- Rank IC；
- ICIR；
- Top组未来收益；
- 多空组合收益；
- 最大回撤；
- 换手率；

- 启动信号后的平均超额收益；

## 34. 防未来函数要求

必须遵循：

- 板块成分股使用历史版本；
- 财务数据按实际披露日生效；
- 盈利预测使用当日可见数据；
- 产业高频数据按发布日期进入；
- 指数成分调整按正式生效日处理；
- 不使用当前业务分类回溯历史；
- 不使用未来修订后的财务数据替代当时数据。

## 35. 数据质量控制

数据质量标记：

```text
NORMAL
MISSING
STALE
OUTLIER
LOW_COVERAGE
CONSTITUENT_CHANGE
SUSPENSION_IMPACT
```

降低置信度的情形：

- 有效成分股少于15只；
- 停牌股票权重超过15%；
- 基本面覆盖率低于60%；
- 盈利预测覆盖率低于40%；
- 产业高频数据超过两个月未更新；
- 单只股票贡献超过板块日收益的50%；
- 新板块历史数据不足120个交易日。

建议输出：

```math
AdjustedPriority
=
PriorityScore \times Confidence
```

同时保留原始得分和置信度。

## 36. 实施顺序

### 第一阶段：板块定义和历史成分股

完成：

- 30个板块定义；
- 核心股、受益股和观察股；
- 业务相关度；
- 历史版本；
- 纳入依据。

### 第二阶段：板块强度分

先实现：

- 相对趋势；
- 扩散改善；
- 资金确认；
- 趋势稳定性；
- 龙头集中度。

该阶段主要用于识别市场主线，不直接生成买入建议。

### 第三阶段：板块机会分

逐步加入：

- 财务景气；
- 盈利预测调整；
- 产业高频；
- 估值匹配；
- 价格位置；
- 拥挤程度。

### 第四阶段：行业与板块融合

形成：

```text
行业评分
+
板块强度
+
板块机会
+
个股技术
+
个股基本面
+
个股风险
```

### 第五阶段：回测和参数优化

重点验证：

- 是否降低高位追涨；
- 是否提高低位启动识别能力；
- 是否降低组合回撤；
- 是否对行业模型提供显著增量。

## 38. 与原方案相比的主要修订

### 删除

- 120日收益作为主要趋势指标；
- 多套均线排列评分；
- 趋势斜率重复计分；
- 相对多个市场基准的重复收益指标；
- 成交额和换手率线性加分；


```text

```

- 强度分；
- 机会分；
- 价格位置评分；
- 拥挤惩罚；

- 扩散背离；
- 强势但不追；

- 硬约束机制。

## 39. 最终结论

板块评分不能仅寻找“当前涨得最好”的板块，而应识别以下组合：

```text
基本面改善
+ 盈利预期上修
+ 市场开始确认
+ 内部扩散增强
+ 价格尚未过度透支
+ 交易尚未过度拥挤
```

趋势指标仍然必要，但其作用应限定为确认市场共识，而不是直接代表买入机会。

本方案将板块评分拆分为“强度分”和“机会分”，能够区分：

- 真正可参与的强势主线；
- 高位拥挤但仍然强势的板块；
- 低位基本面改善但尚未确认的板块；
- 趋势和基本面均较弱的板块。

相较于单一趋势评分，该结构更有利于降低追涨杀跌，提高板块轮动和个股筛选中的收益风险比。

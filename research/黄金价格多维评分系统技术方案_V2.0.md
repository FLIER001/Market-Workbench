# 黄金价格多维评分系统技术方案（精简版）

> 版本：V2.1（沿用 V2.0 文件名）  
> 目标：建立一个仅包含“框架—维度—指标—评分”的黄金价格环境判断系统，不承担精确目标价预测，也不直接输出机械交易指令。  
> 适用标的：国际现货黄金、COMEX黄金；人民币黄金可在总分基础上增加汇率修正层。

---

## 1. 结论

黄金评分系统采用 **5个维度、8个核心指标、总分100分**。

| 维度 | 权重 | 核心作用 |
|---|---:|---|
| 机会成本与美元 | 40% | 决定黄金最主要的短中期宏观定价方向 |
| 投资资金与仓位 | 25% | 判断新增资金是否支持价格趋势及仓位是否拥挤 |
| 金融风险与避险环境 | 10% | 判断风险事件是否转化为有效黄金需求 |
| 结构性需求 | 15% | 判断央行和亚洲实物需求是否抬高价格中枢 |
| 趋势确认 | 10% | 捕捉市场自身的趋势延续与反转状态 |

核心评分仅保留以下8项：

1. 美国10年期实际利率；
2. 美联储广义贸易加权美元指数；
3. 全球实物黄金ETF超预期流量；
4. COMEX管理基金净多头动量；
5. OFR金融压力指数（剔除安全资产类别）；
6. 全球已报告央行滚动储备变动；
7. 上海—伦敦黄金溢价；
8. 黄金中期风险调整动量。

CPI、名义美债收益率、油价、VIX单项、非农、PMI、矿山产量、金饰需求、财政赤字、RSI、MACD等不进入核心总分，只作为事件解释或风险备注。

---

## 2. 设计原则

### 2.1 少而有效

每个指标必须至少满足以下三项：

- 具有清晰的黄金定价机制；
- 能获得稳定、可持续更新的数据；
- 与其他指标不存在严重重复；
- 在不同样本阶段具有相对稳定的方向；
- 能改善未来1周至3个月黄金收益或趋势状态的识别；
- 不依赖主观文本判断。

### 2.2 分层而不重复

- 实际利率已经包含名义利率和通胀预期信息，不再重复纳入名义收益率、盈亏平衡通胀率和政策利率。
- 美元指数已经反映美国相对增长、利差和全球美元需求，不再单独纳入大量宏观数据。
- OFR金融压力信号仅汇总信用、股票估值、融资和波动率四类贡献；安全资产类别含黄金价格，不进入黄金评分，避免目标泄漏。
- 趋势指标只保留一个风险调整动量，不叠加MACD、RSI、均线多头排列等高度相关指标。

### 2.3 区分方向与拥挤度

部分指标具有非线性：

- ETF增持通常利多，但极端集中流入可能意味着短期过热；
- COMEX净多头增加通常利多，但仓位处于历史极高分位时，新增利多空间下降；
- 金融压力上升通常利多黄金，但若同时伴随美元和实际利率快速上升，可能是流动性或通胀冲击，黄金未必上涨。

因此，评分系统需设置拥挤度惩罚和状态条件，而不能机械线性累加。

## 5. 指标计算

### 5.1 G01：美国10年期实际利率

```text
G01原始信号
= -[0.6 × 20日实际利率变化
  + 0.4 × 60日实际利率变化]
```

实际利率下降，信号为正；实际利率上升，信号为负。

保留理由：黄金不产生现金流，实际利率代表持有黄金相对于实际无风险资产的机会成本，是短中期最稳定的解释变量之一。

不重复纳入美国10年期名义收益率、2年期美债收益率、联邦基金目标利率、10年期盈亏平衡通胀率、CPI和PCE。这些指标可用于解释实际利率为何变化，但不进入总分。

### 5.2 G02：广义贸易加权美元指数

优先使用美联储广义贸易加权美元指数，而不是只覆盖少数发达经济体货币的DXY。

```text
G02原始信号
= -[0.6 × 美元指数20日对数收益率
  + 0.4 × 美元指数60日对数收益率]
```

美元贬值为正信号，美元升值为负信号。

### 5.3 G03：全球实物黄金ETF超预期流量

使用全球实物支持黄金ETF的持仓吨数，不使用资产管理规模，因为资产管理规模会受到金价上涨的被动抬升。

```text
ETF原始流量
= 0.7 × 4周持仓吨数变化率
+ 0.3 × 12周持仓吨数变化率

ETF原始流量_t = α_t + β_t × 黄金风险调整动量_t + ε_t

G03原始信号 = ε_t 的4周指数移动平均
```

滚动回归最多使用此前156周，至少需要104周；估计当期参数时不得使用当期ETF流量。评分只使用价格动量无法解释的残差，避免ETF追涨资金与G08价格趋势重复计权。页面仍展示全球持仓吨数、原始4/12周流量、模型解释值和超预期流量。ETF按实际发布日期进入回测。

### 5.4 G04：COMEX管理基金净多头动量

```text
净多头占比
=（管理基金多头合约－管理基金空头合约）
 ÷ COMEX黄金总未平仓合约

G04基础信号
= 净多头占比的4周变化
```

拥挤度修正：

| 当前净多头占比历史分位 | 修正规则 |
|---|---|
| 0%—80% | 不修正 |
| 80%—90% | 指标得分上限80分 |
| 90%—95% | 指标得分上限65分 |
| 95%以上 | 指标得分上限50分 |
| 10%以下且4周净多头回升 | 可保留高分，视为低位修复 |

### 5.5 G05：OFR金融压力指数（剔除安全资产）

使用美国金融研究办公室发布的OFR FSI分类贡献。因安全资产类别直接包含 Gold/USD Real Spot Exchange Rate，黄金评分仅汇总信用、股票估值、融资和波动率四类贡献，避免将黄金价格自身作为黄金的解释变量。

```text
OFR ex-safe
= 信用贡献 + 股票估值贡献 + 融资贡献 + 波动率贡献

G05基础信号
= 0.7 × OFR ex-safe 20日变化
+ 0.3 × OFR ex-safe 当前水平
```

状态修正：

```text
若美元20日上涨，且10年期实际利率20日上升：
G05最终得分 = min（G05基础得分，50）
```

金融压力上升可能推动黄金，也可能引发现金和美元需求，因此不能直接用VIX上涨机械判定利多。

### 5.6 G06：全球已报告央行滚动储备变动

```text
G06原始信号
= IMF IFS全球官方黄金储备本月存量
－ 12个月前存量
```

采用滚动12个月变动，而不是单月值，以降低申报滞后和补报造成的噪声。该数据只代表已报告官方储备变动，不包含尚未披露交易；历史迟报修订按抓取日留存版本。该项主要影响中长期价格中枢和回撤支撑，不承担日频择时功能。

### 5.7 G07：上海—伦敦黄金溢价

```text
上海—伦敦溢价
= 上海黄金基准价PM（SHAUPM）折算美元/盎司
－ LBMA Gold Price AM

G07原始信号
= 当前20日平均溢价
－ 过去3年滚动中位数溢价
```

采用世界黄金协会公开方法中的 SHAUPM 对 LBMA AM，二者交易窗口相对接近；该值是方向性理论价差，不是可交易套利价差。应扣除正常进口、融资和交易成本形成的长期基准差，并使用20日平均值避免交易时点、汇率和节假日错位。

### 5.8 G08：黄金风险调整动量

```text
60日风险调整动量
= 黄金60日收益率 ÷ 60日年化波动率

120日风险调整动量
= 黄金120日收益率 ÷ 120日年化波动率

G08原始信号
= 0.6 × 60日风险调整动量
+ 0.4 × 120日风险调整动量
```

只保留一个中期风险调整动量，避免重复使用RSI、MACD和多组均线。

## 6. 标准化与单项评分

所有原始信号统一转换为滚动历史分位数：

```text
单项得分 = 原始信号在过去5年中的历史分位数 × 100
```

要求：

- 高频指标使用过去5年日频或周频数据；
- 央行储备变动使用2010年以来月度数据；
- 最短样本不少于3年；
- 单项得分限制在0—100分；
- 推荐采用分位数而不是固定Z分数，降低极端行情影响；
- G01、G02、G05、G07、G08日频信号采用3日指数移动平均；G03残差采用4周指数移动平均；
- 央行月度指标按最新公布版本直接更新，并留存历史数据版本。

缺失值处理：

| 情况 | 处理 |
|---|---|
| 最新观测在该来源正常发布窗口内 | 正常权重 |
| 抓取回退同源快照，或最新观测超过来源时效阈值 | 标记陈旧，指标权重乘以0.5 |
| 无同源有效数据 | 暂停该指标，剩余指标权重按比例归一化 |
| 央行数据处于正常月度公布间隔 | 不视为缺失 |

## 7. 维度得分与总分

```text
机会成本得分
= G01 × 62.5% + G02 × 37.5%

投资资金得分
= G03 × 60% + G04 × 40%

风险环境得分
= G05

结构需求得分
= G06 × 66.7% + G07 × 33.3%

趋势确认得分
= G08
```

```text
黄金总分
= 机会成本得分 × 40%
+ 投资资金得分 × 25%
+ 风险环境得分 × 10%
+ 结构需求得分 × 15%
+ 趋势确认得分 × 10%
```

总分范围为0—100分。

## 8. 评分解释

| 总分 | 环境判断 | 含义 |
|---:|---|---|
| 80—100 | 强利多 | 多数核心驱动一致利多，且资金与趋势确认 |
| 65—79 | 利多 | 黄金宏观环境偏强，但可能存在局部冲突 |
| 45—64 | 中性 | 驱动分化，价格更可能震荡或由事件主导 |
| 20—44 | 利空 | 机会成本或资金条件明显不利 |
| 0—19 | 强利空 | 多数核心驱动一致利空 |

建议设置滞后区间，减少频繁切换：

- 中性转利多：总分连续3日高于65；
- 利多转中性：总分低于55；
- 中性转利空：总分连续3日低于40；
- 利空转中性：总分高于50。

## 9. 一致性与置信度

将5个维度划分为：利多（不低于60）、中性（40—59）、利空（低于40）。

```text
方向一致性
= 与总分方向一致的维度权重之和
```

| 条件 | 置信度 |
|---|---|
| 方向一致性不低于75%，无重要数据缺失 | 高 |
| 方向一致性50%—75% | 中 |
| 方向一致性低于50%，或实际利率与资金方向显著冲突 | 低 |

推荐输出：

```text
黄金总分：72
方向：利多
置信度：中
主要正贡献：实际利率、ETF持仓、趋势
主要负贡献：美元、COMEX仓位拥挤
```

## 10. 人民币黄金修正层

```text
人民币黄金参考分
= 国际黄金总分 × 90%
+ 人民币汇率得分 × 10%
```

人民币汇率得分采用美元兑人民币20日、60日变化的历史分位数。人民币贬值提高人民币黄金得分，人民币升值降低人民币黄金得分。上海—伦敦溢价已进入结构需求维度，不重复计分。

## 11. 不进入核心评分的指标

| 指标 | 处理 | 原因 |
|---|---|---|
| CPI、核心PCE | 事件解释 | 对黄金影响需经过实际利率和政策反应传导，方向不稳定 |
| 名义美债收益率 | 剔除 | 与实际利率高度重复 |
| 盈亏平衡通胀率 | 剔除 | 已包含在实际利率分解中，单独加入易重复计分 |
| 美联储降息概率 | 事件解释 | 预期通常已反映在实际利率和美元中 |
| 非农、失业率、PMI | 事件解释 | 数据本身方向不固定，需观察对利率和美元的影响 |
| VIX | 剔除 | 单一股票波动指标不能代表金融压力，避险关系具有状态依赖 |
| MOVE、信用利差 | 不单列 | 已由OFR金融压力指数综合覆盖 |
| 原油价格 | 事件解释 | 既可能强化通胀和利率压力，也可能强化避险需求 |
| 地缘政治风险指数 | 观察项 | 月频、文本构造且影响取决于美元和利率反应 |
| 美国财政赤字、债务 | 长期观察 | 方向和时间滞后不稳定，不适合日周频打分 |
| 矿山产量、生产成本 | 长期观察 | 供给弹性低，难以解释短中期价格 |
| 金饰消费 | 长期观察 | 经常受到金价反向影响，存在明显内生性 |
| 回收金供应 | 长期观察 | 多为价格上涨后的结果，反向因果较强 |
| 金银比 | 辅助观察 | 同时受白银工业属性影响，不是纯黄金驱动 |
| RSI、MACD、多组均线 | 剔除 | 与风险调整动量高度重复，容易造成技术指标堆叠 |
| 分析师目标价 | 剔除 | 主观性强、更新不一致，无法稳定标准化 |

## 13. 回测与指标保留标准

分别检验未来5日、20日和60日黄金收益，以及未来20日最大回撤和趋势状态。

评价指标包括：总分与未来收益的秩相关系数、各评分区间未来收益的单调性、方向准确率、AUC、信息系数、最大回撤和跨宏观阶段稳定性。

某指标需同时满足：

- 样本外方向与理论方向一致；
- 至少在5日、20日或60日中的一个期限具有稳定增量信息；
- 加入后没有明显降低模型跨阶段稳定性；
- 与现有指标的绝对相关系数原则上低于0.80；
- 数据发布时间明确，回测中不存在未来函数。

不满足条件的指标应删除，而不是通过降低权重长期保留。

## 16. 主要研究依据

- World Gold Council, *Gold Return Attribution Model*：将黄金驱动归纳为经济扩张、风险与不确定性、机会成本和动量，并强调驱动关系会随时间变化。
- Federal Reserve Bank of Chicago, *What Drives Gold Prices?*：重点检验通胀预期、长期实际利率和宏观悲观预期对黄金价格的影响。
- Office of Financial Research, *OFR Financial Stress Index*：提供信用、融资、估值、安全资产和波动率等分类贡献；安全资产类别含黄金价格，因此本方案将其剔除。
- CFTC, *Disaggregated Commitments of Traders*：将黄金期货交易者区分为生产商、掉期交易商、管理基金和其他可报告交易者。
- IMF, *Gold as International Reserves: A Barbarous Relic No More?*：说明经济金融不确定性、替代资产收益率和金融制裁风险与央行黄金储备配置有关。
- IMF, *Gold in Central Bank Reserves: Strategic Considerations, Market Risks, and Practical Guidance*：强调黄金的避险和分散化作用具有状态依赖性，并区分实物积累与价格重估。
- World Gold Council, *Central Bank Gold Reserves Survey 2026*：显示过去四年央行年均增持约1000吨黄金，结构性官方需求明显高于此前十年。
- 黄金避险与商品趋势研究文献：黄金的避险属性并非在所有波动状态下成立；商品期货趋势跟随具有一定稳健性，因此风险指标需进行状态修正，技术维度仅保留单一趋势指标。

## 17. 版本结论

本系统保留能够代表五条尽量独立的定价渠道的少量指标：

```text
实际利率与美元
→ 超预期ETF资金与期货仓位
→ 金融风险
→ 央行与亚洲结构性需求
→ 价格趋势确认
```

完整版本为 **5维8指标**；数据接入初期可先使用 **6指标最小可用版本**。宏观数据、地缘事件和供需统计用于解释评分变化，不直接进入总分，避免重复计分和指标堆叠。

# 基金模块开源项目调研（GitHub 高星）

调研时间：2026-08-05 ｜ 渠道：agent-reach（GitHub / gh CLI）｜ Star 数为当日实时数据

## 一句话结论

中国公募基金方向，「数据层」已经非常成熟（efinance / akshare / xalpha），直接复用即可；「产品层」高星项目以 Chrome 扩展和脚本为主，FastAPI + React 全栈形态只有低星新作——这正是 Vibe-Research 可以做出差异化的位置。建议按下面的三层架构选型：

> **efinance（实时估值/行情）＋ xalpha（组合账本与回测引擎）＋ akshare 存量能力（档案/持仓/排名），自研产品层。**

## 第一梯队：直接可复用的库（建议引入）

### 1. efinance ★3,922 ｜ Python ｜ 维护活跃（2026-07）
- 定位：股票、**基金**、债券、期货数据获取库，东方财富/天天基金数据源。
- 基金能力：实时估值、历史净值、持仓明细、基金经理、基金评级、场内 ETF 行情。
- 与本项目关系：后端已是 FastAPI + Python，`pip install efinance` 即可用，API 风格与 akshare 一致，是最低成本的基金数据入口。
- 风险：依赖网页接口，存在限流（作者也提示了），需配合缓存与降级。

### 2. xalpha ★2,672 ｜ Python ｜ 维护活跃（2026-07）
- 定位：「基金投资的全流程管理」——基金投资管理回测引擎。
- 核心能力：
  - `xa.fundinfo("501018")` 一行拿基金信息；`xa.get_daily / get_rt` 统一日线/实时数据；
  - `xa.record(csv)` 读入账单 + `xa.mul(...)` 精确到分的组合账本，特别适合**反复进出的定投/网格型**投资；
  - 基金组合**底层股票持仓透视**（`get_stock_holdings()`）——可看到一篮子基金等效持股；
  - 定投/网格策略回测与定时提醒；QDII 基金 T-0 净值预测；指数/基金历史估值（PEBHistory）。
- 与本项目关系：可整体作为基金模块的**组合/回测引擎**，避免自己实现 XIRR、份额确认、分红再投资这些易错细节。已有 AI agent 原生支持（MCP 友好）。
- 注意：部分估值功能依赖聚宽数据，需评估或绕过。

### 3. akshare ★21,798（本项目已依赖 >=1.10）
- 已有大量基金接口（`fund_open_fund_info_em`、`fund_portfolio_hold_em`、`fund_rating_all`、ETF 实时行情等），无需新增依赖，适合作为档案/持仓/评级数据的补充源。

## 第二梯队：功能与交互设计的参考对象

### 4. x2rr/funds（自选基金助手）★3,202 ｜ Vue + Chrome 扩展 ｜ 维护活跃
中国基金类星数最高的产品型项目。功能清单几乎就是「基金模块」的需求文档：
- 实时估值角标、份额/成本价/加仓减仓、持有收益与当日估值收益；
- 估值走势、净值走势、收益走势图；基金股票持仓明细、基金经理信息；
- 基金分组、拖拽排序、模糊搜索批量添加、节假日休市判断、暗色主题、账号同步。
- **可借鉴**：信息密度极高的紧凑列表 UI（与本项目「金融终端风」取向一致）、估值 vs 净值的双线呈现、休市态处理。

### 5. axiaoxin-com/investool ★2,235 ｜ Go + Web ｜ 最后更新 2025-06
- 基金侧功能：**4433 法则筛选**、自定义基金筛选、基金检测、**股票选基**（输入股票找重仓基金）、基金持仓相似度、基金经理筛选。
- 数据源：东方财富、天天基金、亿牛网——与本项目可复用源一致。
- **可借鉴**：筛选规则是一套成熟可落地的基金评价方法论；估值告警思路可移植。

### 6. HKUSTDial/DeepFund ★289 ｜ Python ｜ NeurIPS 2025
- LLM 多智能体基金投资研究框架（trading arena，不下单），学术背书强、理念新。
- **可借鉴**：多源信息 → 多智能体 → 可解释交易决策的管线，契合本项目「AI 判断 + 可点证据」的方向；但工程上不建议依赖（重、研究性质、不交易）。

## 对本项目基金模块的建议

### 架构（贴合现有 FastAPI + React 结构）

```
backend/fund.py                 # 新模块，参考 astock.py 模式
  ├─ 数据层：efinance 实时估值/行情 ＋ akshare 档案/持仓/评级（缓存+降级，复用 _cached 模式）
  ├─ 引擎层：xalpha（账单账本、定投回测、XIRR、底层持仓透视）
  └─ API：/api/fund/search、/api/fund/{code}/valuation、/api/fund/{code}/profile、
          /api/fund/portfolio（与现有 portfolio.py 打通）
frontend/src/pages/Fund.tsx + router 注册（参考 StockData/Portfolio 页）
```

### 功能分期

- **P0 自选基金**：基金搜索（拼音/代码模糊匹配）、实时估值、净值/估值走势图、成本价与份额收益——对标 x2rr/funds 的核心体验；
- **P1 基金画像**：档案（经理/规模/费率/评级）、持仓明细、技术指标（最大回撤/夏普/波动率）——数据来自 akshare + efinance；
- **P2 组合与筛选**：基金组合账本（xalpha）、底层股票持仓透视、4433 筛选、股票选基；
- **P3 AI 判断**：接入现有 backgroundTasks/AskAiButton 体系，输出「观点一段话 + 可点证据」，风险评分可参考 nai-he/fund-analysis-agent 的做法。

### 风险提示

1. efinance/akshare 均为网页接口，**限流与字段漂移是常态**：估值类接口务必加缓存（本项目已有 `_cached` 模式）与多源降级；
2. 基金实时估值 = 根据上季重仓股推算，**与真实净值有偏差**，UI 上必须区分「估值」与「净值」（x2rr/funds 的处理方式值得照抄：交易日净值更新后打 √）；
3. xalpha 部分估值功能依赖聚宽数据，引入前先验证所需接口的可用性；
4. 所有项目均声明「仅供学习研究」，本项目对外展示时需保留类似免责口径。
